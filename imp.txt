================================================================================
ملف خطوات تشغيل مشروع تشخيص أمراض الكلى (Kidney Disease Awareness)
================================================================================

⚠️ تنبيه هام:
يجب تشغيل الـ 3 خطوات التالية بالترتيب، ولا تغلق أي شاشة سوداء (Terminal) تفتحها.

--------------------------------------------------------------------------------
🟢 الخطوة الأولى: تشغيل قاعدة البيانات (MongoDB)
--------------------------------------------------------------------------------
1. افتح الـ CMD كـ مسؤول (Run as Administrator).
2. انسخ هذا الأمر للانتقال لمجلد التسطيب (تأكد من رقم النسخة 7.0 أو 8.0):
   cd "C:\Program Files\MongoDB\Server\8.0\bin"

3. شغل السيرفر بهذا الأمر:
   mongod --dbpath="C:\data\db"

✅ علامة النجاح: الشاشة ستتوقف عن الكتابة ولن تغلق.
⛔ تحذير: لا تغلق هذه الشاشة أبداً، فقط قم بتصغيرها (Minimize).

--------------------------------------------------------------------------------
🟠 الخطوة الثانية: تشغيل الـ AI Model (Python)
--------------------------------------------------------------------------------
1. افتح تيرمينال جديد (داخل مجلد AI_Service).
2. فعل البيئة الوهمية:
   .\venv\Scripts\activate

3. شغل السيرفر:
   python app.py

✅ علامة النجاح: ستظهر رسالة "Running on http://127.0.0.1:5000".

--------------------------------------------------------------------------------
🔵 الخطوة الثالثة: تشغيل الـ Backend (Node.js)
--------------------------------------------------------------------------------
1. افتح تيرمينال جديد (داخل مجلد Backend).
2. شغل السيرفر:
   npm start

✅ علامة النجاح: ستظهر رسالة "Server is running on port 3000" و "MongoDB connected".

================================================================================
🧪 أكواد اختبار Postman (جاهزة للنسخ)
================================================================================

1️⃣ تسجيل مستخدم جديد (Register)
--------------------------------
* Method: POST
* URL: http://localhost:3000/api/users/register
* Body (JSON):
{
  "firstName": "Ahmed",
  "lastName": "Ali",
  "email": "ahmed@example.com",
  "password": "password123",
  "gender": "male"
}

2️⃣ تسجيل الدخول (Login)
--------------------------------
* Method: POST
* URL: http://localhost:3000/api/users/login
* Body (JSON):
{
  "email": "ahmed@example.com",
  "password": "password123"
}
⚠️ انسخ الـ "token" من الرد، ستحتاجه في الخطوة التالية.

3️⃣ تشخيص المرض (Diagnosis)
--------------------------------
* Method: POST
* URL: http://localhost:3000/api/diagnose
* Headers:
    Key: token
    Value: Bearer [ضع_التوكن_هنا]
* Body (JSON):
{
  "symptoms": {
    "back_pain": 1,
    "swelling": 0,
    "low_urine": 1,
    "fever": 1,
    "blood_in_urine": 0,
    "nausea": 1,
    "vomiting": 0,
    "fatigue": 1,
    "loss_of_appetite": 0,
    "burning_urination": 1,
    "dark_urine": 0,
    "abdomen_pain": 0
  },
  "additionalNotes": "تجربة نهائية"
}

================================================================================
🛠️ حلول سريعة للمشاكل (Troubleshooting)
================================================================================
1. خطأ "connect ECONNREFUSED 127.0.0.1:27017"
   -> معناه أنك نسيت الخطوة الأولى (الشاشة السوداء للمونجو مغلقة).

2. خطأ "connect ECONNREFUSED 127.0.0.1:5000"
   -> معناه أن سيرفر البايثون (الخطوة الثانية) مغلق.

3. خطأ "401 Unauthorized" في Postman
   -> معناه أنك نسيت تضع الـ token في الـ Headers.
